# Fashion MNIST Clothing Classification

## Overview
Built a Multi-Layer Perceptron (MLP) to classify clothing images across 10 categories using the Fashion MNIST dataset.

## Results
- 87.98% test accuracy on 10-class classification
- Experimented across 9 model configurations

## What I explored
- Effects of dropout, learning rate, and network depth
- Data augmentation techniques
- Hyperparameter tuning

## Tools
- Python
- PyTorch
- Jupyter Notebook

## Dataset
Fashion MNIST — 70,000 grayscale images of clothing items
